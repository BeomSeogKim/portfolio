# 리세일 시스템 마이그레이션

> 기간: 2026.02 ~ 2026.05
> AI를 활용해 중단된 리세일 시스템 마이그레이션을 재개하고 신규 시스템 출시

기존 시스템은 상품의 판매 방식이 바뀔 때마다 새로운 상품으로 관리해 변경 전후의 이력을 추적하기 어려웠습니다. 이를 개선하려던 마이그레이션이 여러 차례 일부 진행 후 중단되면서 레거시와 신규 흐름이 함께 남아 복잡도가 누적됐습니다.

중단된 프로젝트를 인수해 약 3개월 동안 레거시와 신규 시스템의 차이를 파악하고 신규 시스템 출시까지 진행했습니다. 두 명이 진행한 프로젝트에서 업무 맥락 정리, AI 구현 계획 검토, 기능 구현과 결과 검증을 담당했습니다.

초기에는 도메인을 충분히 이해하지 못한 상태에서 레거시·신규 프로젝트를 한 디렉토리에 모아두고, AI에 레거시를 참고해 신규 시스템의 미구현 기능을 개발하도록 요청했습니다. AI가 업무 맥락까지 파악할 것이라 기대했지만, 의도와 다른 기능이 반복적으로 구현돼 코드를 폐기했습니다. 약 3일간의 시행착오 후 해외 활용 사례를 참고해, 업무 맥락과 수정 범위를 먼저 구체화하고 구현 전 계획을 검토·승인하는 방식으로 전환했습니다.

- **업무 맥락 구체화:** 실무자와 업무 흐름·문제 상황을 확인하고, AI가 조사할 맥락과 수정 범위를 정리
- **계획 검토·구현:** 변경 범위와 검증 방법을 담은 AI의 구현 계획을 검토·승인. 필요에 따라 다른 벤더의 AI 에이전트로 계획·코드를 교차 검증
- **결과 검증:** 개인 식별 정보를 제외한 업무 기준 자료로 이관 금액을 대조하고, 발견한 차이를 수정한 뒤 다시 확인. 구현한 기능은 테스트와 개발 환경의 E2E로 동작 확인
- **지식 축적:** 확인한 도메인 규칙과 문제 해결 과정을 작업 공간에 기록해 이후 AI 작업의 맥락으로 재사용

이관 데이터에서 발견한 정산 금액 차이와 상품 상태 오류를 수정하고, 신규 시스템의 상태 전환 로직에서 확인한 결함을 출시 전에 보완했습니다. 출시 후에는 AI를 활용해 운영 이슈를 병렬로 처리하며 운영 안정화에 기여했습니다.
