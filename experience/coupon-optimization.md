# 쿠폰 조회 성능 개선

> 기간: 2024.10 ~ 2024.11
> 쿠폰 증가로 발생한 조회 병목을 N+1 해소와 쿼리 통합으로 개선

상품별 쿠폰이 도입되며 조회 대상이 크게 늘어난 뒤, 상품 상세와 결제 화면의 쿠폰 조회에서 지연과 오류가 발생했습니다. Slack 오류 알림을 계기로 장애 대응에 참여하고, 쿠폰 조회 구조 개선을 담당했습니다.

- **연관 데이터 조회 개선:** 쿠폰과 조건을 함께 읽도록 fetch join을 적용해 연관 데이터를 건별로 다시 조회하던 N+1 문제를 줄였습니다.
- **반복 집계 통합:** 각 쿠폰마다 따로 실행하던 다운로드·사용 횟수 조회를 상관 서브쿼리 기반 프로젝션으로 합쳐 쿠폰 목록과 필요한 집계 값을 한 번에 조회하도록 변경했습니다.

## 핵심 흐름

문제 해결 흐름을 단순화한 개념도입니다.

```mermaid
flowchart LR
    A[사용 가능 쿠폰 요청] --> B[쿠폰과 조건 함께 조회]
    B --> C[필요한 집계 값 통합 조회]
    C --> D[사용 가능 여부 계산]
    D --> E[쿠폰 목록 응답]
```

개선 전후의 응답 시간을 비교해 결제 화면의 사용 가능 쿠폰 조회를 약 12초에서 0.3초로, 전체 사용자 대상 쿠폰 조회를 약 5초에서 1초로 단축했습니다. 이 수치는 당시 측정에 대한 회고이며 측정 로그는 공개 자료에 포함하지 않았습니다.
