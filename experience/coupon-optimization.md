# 쿠폰 조회 성능 개선

> 기간: 2024.10 ~ 2024.11
> 쿠폰 증가로 발생한 조회 병목을 N+1 해소와 쿼리 통합으로 개선

상품별 부착 쿠폰 도입으로 활성 쿠폰이 약 90개에서 9,000개로 증가한 뒤, 상품 상세·결제 화면의 쿠폰 조회에서 지연과 오류가 발생했습니다. Slack 오류 알림을 계기로 장애 대응에 참여하고, 쿠폰 조회 구조 개선을 담당했습니다.

- **연관 데이터 조회 개선:** 쿠폰 조건 조회에 fetch join을 적용해 연관 데이터의 개별 조회로 발생하던 N+1 문제를 해소
- **반복 쿼리 통합:** 쿠폰마다 실행하던 다운로드·사용 횟수 COUNT 쿼리를 Native SQL의 상관 서브쿼리로 통합해, 쿠폰 정보와 함께 조회하도록 변경

결제 화면의 사용 가능 쿠폰 조회 시간을 약 12초에서 0.3초로, 전체 사용자 대상 쿠폰 조회 시간을 약 5초에서 1초로 단축했습니다.
