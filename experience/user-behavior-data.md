# BytePlus 개인화 추천 연동 및 이벤트 처리 개선

> 기간: 2024.07 ~ 2025.03
> 개인화 추천 도입과 대규모 사용자 행동 이벤트 파이프라인 구축·개선

개인화 추천 도입을 위한 BytePlus PoC 진행 중 담당 리드가 이탈하면서 프로젝트를 인수했습니다. 검색·상품 상세 등 주요 화면의 추천 API 연동과 A/B 테스트 적용, 추천 모델 학습에 필요한 사용자 행동 이벤트 전송을 담당했습니다.

- **추천 API 연동:** 기존 검색·추천과 BytePlus를 A/B 분기로 연결하고, BytePlus 결과가 없으면 기존 로직으로 응답하도록 구성.
- **이벤트 처리 개선:** 일 약 300만 건의 사용자 행동 이벤트를 전송하는 Kafka 기반 파이프라인을 구축. 건별 동기 API 호출로 이벤트가 적체되자, Kafka Batch Listener와 최대 150건 단위의 배치 API 호출로 전환.

주요 화면에 개인화 추천을 적용하고 기존 추천과 비교할 수 있는 환경을 마련했습니다. 배치 처리 전환으로 하루 가까이 지연되던 사용자 행동 이벤트 전송을 실시간 수준으로 회복했습니다.
