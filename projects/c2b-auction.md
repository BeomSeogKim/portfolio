# C2B 경매 서비스 개발

> 기간: 2025.04 ~ 2025.07
> 도메인 모델과 테스트를 기반으로 변화하는 경매 정책에 대응하며 백엔드 전반 개발

핵심 경매 절차가 확정되지 않은 상태에서 약 2개월 내 출시를 목표로 개발에 착수했습니다. 데이터 구조 설계부터 백엔드 API 개발까지 단독으로 담당했으며, 개발과 동시에 기획자·실무자와 세부 업무 규칙을 구체화해야 했습니다.

- **도메인 문서를 통한 업무 규칙 조율:** 경매 등록부터 재경매·위탁 전환까지의 절차와 조건을 문서로 정리하며 기획과 실제 업무의 차이를 확인했습니다. 위탁 상품도 검수를 거치도록 한 초기 기획은 실무자와 논의한 결과 이미 검수가 완료된 상품임을 확인해, 추가 검수 없이 경매를 시작하는 흐름으로 변경했습니다.
- **변경을 고려한 도메인 책임 분리:** 경매 상품·경매 회차·위탁 전환의 책임을 나누고, 재경매 가능 여부와 같은 업무 규칙을 해당 모델에서 판단하도록 구성했습니다. 위탁 상품의 검수 절차가 변경됐을 때도 기존 구조에서 경매 시작 조건을 수정해 반영할 수 있었습니다.
- **테스트를 통한 업무 규칙 검증:** 재경매가 가능한 상태·회차와 위탁 전환 조건 등을 테스트로 검증했습니다. 경매 모델이 크게 변경되는 과정에서는 기존 테스트를 기준으로 놓친 조건을 발견하고 보완하며, 변경 후에도 지켜야 할 규칙을 확인했습니다.

핵심 기획이 3~4차례 변경되는 과정에서도 약 2개월의 목표 일정에 맞춰 출시했으며, 구현한 경매 흐름이 의도한 업무 규칙대로 동작하는 것을 확인했습니다.
