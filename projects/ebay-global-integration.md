# eBay 상품 연동 자동화 및 고도화

> 기간: 2024.12 ~ 2025.09
> 수기 상품 등록을 일괄 등록에서 다국가 API 동기화로 단계적 자동화

eBay 상품 등록은 자사 상품 정보를 찾아 수기로 입력하는 방식으로, 등록 물량을 늘리는 데 한계가 있었습니다. 이를 자동화하는 프로젝트를 제안해 승인받았으며, 착수 후 담당자 인터뷰에서 1인당 하루 등록량이 20여 건에 그친다는 점을 확인했습니다.

**1차 — MIP 기반 일괄 등록**

Redash로 상품 정보를 추출하고 Apps Script로 누락 정보 보완·후가공을 지원해, MIP 방식으로 일괄 등록할 수 있도록 구축했습니다. 일 목표 1,000건을 충분히 소화하게 됐으며, 담당자의 작업은 일부 항목 검수·업로드·미진열 상품 정리로 줄었습니다.

**2차 — API 연동 및 구조·성능 개선**

이후 eBay 매출이 증가하며 사업을 본격화했지만, 수기 장부 관리와 미진열 상태의 동기화 지연, 휴먼 에러 가능성이 남아 있어 API 연동으로 확장했습니다.

- **운영 통합:** 상품팀의 NestJS 기반 API 연동 시스템과 협업하며 Java로 상품 데이터 변환 엔진을 개발. 유지보수 분산과 불필요한 네트워크 호출을 줄이고자 TypeScript를 학습해 변환 엔진을 NestJS로 이관.
- **확장 구조 개선:** 상품 동기화·인증·오류 처리가 결합되고 국가별 분기가 여러 계층에 흩어진 구조를 개선. 헥사고날 구조로 책임과 의존성을 나누고, 국가별 설정을 모으고 HTTP 응답 처리와 상품 처리 흐름을 분리.
- **처리 성능 개선:** 단일 워커를 국가별 워커로 분리해 병렬성을 높이고, 일괄 처리가 가능한 API를 배치 호출로 전환.

전체 상품의 전 국가 연동 시간을 약 24시간에서 약 3시간으로 단축했습니다. 수기 등록에서 시작한 자동화를 다국가 API 연동으로 확장해 상품 운영을 지원했습니다.
