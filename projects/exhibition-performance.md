# 기획전 조회 성능 개선

> 기간: 2025.10
>
> Coroutine 병렬화와 Redis 캐시 갱신 개선으로 기획전 응답 지연 해소

Slack의 기획전 응답 지연 알림을 계기로 원인을 조사했습니다. 확인 결과, 10분 캐시가 유효할 때는 드러나지 않던 상품 조회 지연이 캐시 만료 직후 발생해, 고객이 페이지 로딩을 30초 이상 기다리는 경우가 있었습니다.

- **상품 조회 병렬화:** StopWatch로 구간별 실행 시간을 측정해, 상품 묶음의 순차 조회로 대기 시간이 누적되는 병목을 확인. WebFlux 환경에서 Coroutine을 활용해 독립적인 모듈 처리와 모듈 내 상품 조회를 병렬화
- **Redis 캐시 갱신 개선:** 방문이 이어지는 기획전에서 캐시 만료마다 반복되는 대기를 줄이도록, 만료까지 1분 미만일 때 요청이 들어오면 기존 캐시로 응답하면서 백그라운드에서 갱신하도록 변경

캐시 미스 시 응답 시간을 약 30초에서 약 2초로 단축했습니다. 배포 후 3~4일간 모니터링에서 3초 초과 응답이나 지연 알림은 관찰되지 않았습니다.
